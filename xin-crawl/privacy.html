xin_crawl 隱私權政策

xin_crawl 是 Islanderyu 個人自用的工具，不對外提供服務。

  • 存取範圍：只存取作者本人 Google 帳號中指定的一份試算表與一個雲端硬碟資料夾，用來寫入公開貼文的全文、發文時間與截圖。
  • 資料用途：資料只存在作者本人的 Google 帳號與自己的電腦，供留存查核使用，不分享、出售或提供給任何第三方，也不用於廣告或 AI 模型訓練。
  • Google 使用者資料政策：本應用程式使用 Google API 取得的資料，遵守 Google API Services User Data Policy，包含其中的 Limited Use 規定。
  • 撤銷授權：可隨時到 Google 帳戶的「第三方存取權」移除本應用程式。
